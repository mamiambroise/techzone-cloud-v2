# Auth_AIM

## Structure
- **front/** - React app (Vite)
- **backend/** - Node.js + Express API

## Run Backend
```
cd backend
npm install
npm run dev
```

## Run Frontend
```
cd front
npm install
npm run dev
```

Frontend runs on port 5173, backend on port 5000. `/api` requests in the frontend are proxied to the backend.
